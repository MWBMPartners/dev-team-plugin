A legacy root `PROJECT.md` that does carry the marker is summarized where it is: this command moves and commits nothing, and reports the move as pending — "`PROJECT.md` is still at the top level of the project — run `/dev-team-move-ledgers` to move it into `.dev-team/`." 4. Reading these files is all this step does; it never moves, stamps or edits them.
5. If none exist, say there's no active dev-team run and point to `/dev-team` to start one.
Keep it skimmable.
